# NISE SONIC

ブラウザで遊べる、ハリネズミの高速 2D アクションゲームです。
HTML5 Canvas と素の JavaScript だけで一から作っていて、ビルドも外部ライブラリも不要です。

> 本作は 90 年代の高速 2D アクションにインスパイアされた非公式のファンメイド作品です。
> 主人公は「赤いマフラーとゴーグルの青緑のハリネズミ・ニセ」というオリジナルキャラクターで、
> セガの画像・音源などの素材は一切使っていません。グラフィックはすべてコードで描いてからドット絵に変換し、
> 効果音と BGM は Web Audio API でその場で合成しています。

## 見た目のこだわり（メガドライブ風）

- 画面サイズは本家と同じ 320×224。画面には整数倍で拡大して、ドットの大きさをそろえる
- キャラや敵は、形をコードで描いたあと「決まった色だけに減色＋暗い色のふち取り」をしてドット絵にする（`js/pixel.js`）
- 地面は 16×16 の市松模様＋縦じま＋ギザギザの草を 1 ドットずつ生成
- 坂ではキャラが 45 度刻みで傾く、速いほど走りのコマ送りが速くなる
- 文字は 5×7 ドットの自作フォント、空は帯状のグラデーション、水面は行ごとに違う速さでスクロール

## 遊び方

`index.html` をブラウザで開くだけで遊べます（`npx serve .` などでローカルサーバーを立ててもOK）。
GitHub Pages を有効にすると、`.github/workflows/pages.yml` が `main` ブランチへの push ごとに自動公開します。

## 収録内容

- **NISE HILL ZONE ACT 1**：坂・ループ・ジャンプ台・動く足場・スプリング・トゲ
- **NISE HILL ZONE ACT 2**：夕焼けステージ、最後にボス戦
- 坂で加速・減速する本家風の慣性物理（地上速度、転がり、スピンダッシュ、可変ジャンプ）
- リング（被弾で散らばる）・100 枚で 1UP・チェックポイント・ゴール看板・リザルト集計
- アイテムボックス：リング10 / バリア / ハイスピード / 無敵 / 1UP
- 敵ロボ 2 種＋ボス、倒すと動物が飛び出す
- タイトル画面・タイトルカード・ゲームオーバー・エンディング、ハイスコア保存

## ファイル構成

```
index.html        画面とスクリプトの読み込み
js/pixel.js       ドット絵化（減色・ふち取り・キャッシュ）とドット文字
style.css         画面のスケーリングとタッチボタン
js/audio.js       効果音・BGM（Web Audio で合成）
js/input.js       キーボード・タッチ・ゲームパッド
js/level.js       地形ビルダーとステージデータ
js/player.js      プレイヤーの物理
js/objects.js     リング・敵・ギミック・ボス・パーティクル
js/render.js      キャラ・敵・地形・背景・HUD の描画
js/main.js        ゲーム進行・カメラ・メインループ
```

## ステージの作り方

`js/level.js` の `Builder` を使うと、地形を左から順に組み立てられます。

```js
const B = new Builder(16000, 560);
B.rings(100, 26, 5);          // 地面から 26px 上にリング 5 個
B.flat(400);                  // 平地 400px
B.obj('bug', 200, 0);         // 敵を配置
B.hill(480, 70);              // 高さ 70px の丘
B.slope(500, 150);            // 150px 下る坂
B.loop(80);                   // 半径 80px のループ
B.gap(200);                   // 穴
```
